# AM Company 収益化戦略

## コアコンセプト

> **テストエビデンスProを主力事業とし、BOOTH販売をキャッシュフロー＋ブランド構築に活用する**

開発体制: 個人1人 / 副業 or 独立検討中

---

## 1. 収益ポートフォリオ

### Tier S: テストエビデンスPro（主力事業）

- **市場**: 日本のSI業界（年間数兆円規模のテスト工程市場）
- **競合空白**: PaperTester（IE依存）死亡後、「Excel仕様書→操作→検証→エビデンス貼付」の一気通貫ツールが不在
- **単価**: 導入支援 50〜100万円 + 年間保守 20〜50万円
- **目標**: 年間2〜3社契約で年商200〜500万円
- **差別化**: Excel入出力・DB検証・Playwright対応の3点セット

### Tier A: AIツール（成長事業）

- **テクスチャ高画質化** ¥500（現¥400→値上げ）: VRChatクリエイター需要、競合少ない
- **足音AI生成** ¥500: ニッチだが競合ゼロ、ローカルGPU完結が強み
- **目標**: 月50〜100DL × ¥500平均 = 月2.5〜5万円

### Tier B: VRChat OSCツール（集客・ブランド構築）

- **おみくじBot** ¥100 / **デコレーター** ¥200 / **タイマー** ¥200
- 利益は小さいが、BOOTH上の「出品数」と「レビュー」を積み上げてストア信頼度を向上
- **目標**: 月30〜50DL × ¥170平均 = 月5,000〜8,500円

## 2. テストエビデンスPro 営業戦略（最重要）

### フェーズ1: 信頼構築（0〜3ヶ月）

**目的**: 「このツールを作った人」として認知されるポジションを確立する

- [ ] VBA Lite版をQiita/Zennで技術記事として公開（3記事）
  - 記事1:「PaperTesterの後継を作った話 — Playwright × Excel自動化」
  - 記事2:「テストエビデンス作業を90%削減するExcel VBAマクロ」
  - 記事3:「DB検証も自動化 — テストエビデンス自動化ツールの全機能解説」
- [ ] Lite版の無料ダウンロードページを作成（GitHub Releases or BOOTH無料商品）
- [ ] デモ動画（5分以内）を作成してYouTubeに公開
  - 内容: Excel仕様書を読み込む → 自動操作 → スクショ取得 → エビデンスExcel完成
- [ ] Lite版利用者のフィードバック収集体制を構築（Google Form）

### フェーズ2: リード獲得（3〜6ヶ月）

**目的**: 問い合わせが来る状態を作る

- [ ] Qiita記事でSI現場の「あるある」に刺さるタイトルでバズを狙う
- [ ] Twitter/Xで「#テスト自動化」「#SI業界」「#Playwright」で定期発信
- [ ] connpass/TECH PLAYでLT登壇（テスト自動化勉強会）
- [ ] Lite版DL数が100件を超えたら、Pro版の問い合わせフォームを設置
- [ ] 問い合わせ導線: 記事内CTA → Google Form → メール対応

### フェーズ3: 商談・契約（6〜12ヶ月）

**目的**: 最初の有料契約を獲得する

- [ ] 無料PoC（2週間）を提供して効果を実感してもらう
- [ ] PoC結果をもとに導入提案書を作成（工数削減率の定量データ付き）
- [ ] 初回契約を獲得

### 価格体系

| プラン | 初期費用 | 年間保守 | 対象 |
|--------|----------|----------|------|
| スターター | 50万円 | 20万円/年 | 小規模チーム（5人以下） |

### 営業チャネル（すべて無料）

| チャネル | 期待効果 |
|---------|----------|
| Qiita/Zenn技術記事 | 認知獲得・SEO。SI系エンジニアが多い |
| Twitter/X | 即時リーチ。テスト自動化の話題は拡散されやすい |
| connpass LT登壇 | 直接的なリード獲得。質疑で課題ヒアリングも可能 |
| BOOTH無料出品 | Lite版DLでリード獲得 |
| 前職・知人ネットワーク | 最も確度が高い |

## 4. アクションプラン

### 短期（0〜3ヶ月）— 最優先

1. **Lite版の実テストケースでの動作検証を完了する**
2. **Qiita記事を1本公開する**（「PaperTesterの後継を作った話」）
3. **デモ動画を作成する**（Excel→操作→エビデンス生成の一連の流れ）
4. **Lite版ダウンロードページを作成する**（GitHub Releases）
5. **BOOTHにバンドルセットを出品する**（3種）
6. **既存BOOTH商品のサムネイル・説明を改善する**

### 中期（3〜12ヶ月）

1. Qiita記事を3本以上公開（SEOでの流入を安定化）
2. connpassでLT登壇（1回以上）
3. Lite版100DL達成後、Pro版問い合わせフォームを設置
4. 初回PoC案件を1件獲得
5. VRChatツールの新商品を2本追加（音声リアクティブ、Spotify連携）
6. テクスチャ高画質化のexe化（PyInstaller）で購入ハードルを下げる

### 長期（1〜3年）

1. テストエビデンスPro: 年間契約3社以上、年商300万円+
2. VRChat BOOTH: 月間売上5万円+（新商品追加で品揃え拡大）
3. SaaS化検討: テストエビデンスのWeb GUI版（月額制）
4. 法人化: 年商500万円を超えたら個人事業主→法人化を検討

## 6. リスクと対策

| リスク | 影響度 | 対策 |
|--------|--------|------|
| テストエビデンスProの営業が進まない | **高** | Qiita/Zennでの技術記事で認知を先行。無料PoCで導入ハードルを下げる |
| 1人で開発・営業・サポートの限界 | **高** | Pro版は年間3社までに制限。ドキュメント整備でサポート工数を最小化 |
| 競合ツールの出現 | 中 | 「Excel入出力」「DB検証」の差別化を磨く。先行者優位を確保 |
| BOOTH販売が伸びない | 低 | 主力収益ではないため影響は限定的。exe化で購入ハードルを下げる |
| Stable Audioライセンス変更 | 低 | 年商$1M未満は無料。当面リスクなし |
