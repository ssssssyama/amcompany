## 新規プロダクト: 転職AI Webアプリ

### コンセプト

転職活動の「書類作成」をAIで自動化するWebアプリ。
日本の転職市場に特化し、職務経歴書・志望動機の生成を核とする。

### ターゲット

- 転職活動中のビジネスパーソン（25〜40歳）
- 特にIT/Web業界からのキャリアチェンジ層
- 「職務経歴書の書き方がわからない」「応募先ごとにカスタマイズが面倒」という課題を持つ人

### MVP機能

1. **AI職務経歴書ジェネレーター**: 職歴+応募先情報 → 最適化された職務経歴書
2. **AI志望動機ジェネレーター**: 企業情報+経歴 → カスタマイズされた志望動機
3. **自己PR添削**: ユーザーの自己PR文をAIが添削・改善提案

### 技術スタック

- Next.js (App Router) + TypeScript
- Claude API (Anthropic) — AI生成
- Supabase — DB + 認証
- Stripe — 決済
- Vercel — ホスティング
