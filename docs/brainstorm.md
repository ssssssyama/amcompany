## 結論: テストエビデンス自動化ツール

### 課題

日本のSI業界・受託開発で大量に発生する手作業:
1. テスト仕様書（Excel）を見ながらアプリを操作
2. 各ステップで画面のスクリーンショットを撮影
3. DB上のデータが正しいか確認
4. 画面表示が期待通りか目視確認
5. スクショとOK/NG判定をExcelに貼り付けて納品

→ **この作業を自動化するワンストップツールが存在しない**

### 競合調査結果

| ツール | 価格 | カバー範囲 | 空白 |
|---|---|---|---|
| Ranorex | 45~71万円/年 | 操作+スクショ | Excel貼付に非対応。独自レポート |
| TestComplete | 35万円~/年 | 操作+スクショ | Excel貼付に非対応。独自レポート |
| T-DASH | 月4,840円 | 操作+スクショ | 独自UIで操作定義。既存Excelを読まない |
| MagicPod | 月39,800円~ | AI操作+スクショ | 高い。Excel連携が限定的 |
| PaperTester (OSS) | 無料 | Excel読取+操作 | **IE依存で事実上使用不可。後継なし** |
| Power Automate | 無料 | 汎用操作 | テスト特化機能なし。全部自分で組む |
| Excelエビデンスくん | 無料 | スクショ貼付のみ | 自動操作なし。検証なし |

**「Excel仕様書 → 操作 → 検証 → エビデンス貼付」の一気通貫ツールが空白地帯。**

### 参入余地がある理由

1. **PaperTesterの後継が不在**: IE廃止で唯一の該当ツールが死亡。Playwright版は存在しない
2. **商用ツールは「Excelに戻さない」**: 独自レポートを出力。SI業界の「お客様指定Excelに貼って納品」に非対応
3. **日本固有の文化**: Excel仕様書+スクショエビデンスは海外にないため、グローバルツールがカバーしない
4. **RPAは汎用的すぎる**: テスト仕様書の読み取り～エビデンス整理を「自分で全部組む」必要あり

### 機能要件

#### コア機能
1. **Excel仕様書読み取り**: テスト手順・期待値をExcelから読み取る
2. **ブラウザ自動操作**: Playwrightでアプリ操作を自動実行
3. **スクショ自動取得**: 各ステップの画面キャプチャ
4. **Excelエビデンス貼付**: スクショ+結果を元のExcelに自動貼付

#### 検証機能（差別化の核）
5. **画面表示の検証**: 特定要素のテキスト・値が期待通りか自動判定（OK/NG）
6. **DB検証**: テスト操作後にDBに接続し、レコードの値が期待値と一致するか確認
7. **検証結果の記録**: OK/NG判定 + エビデンス（スクショ + DBクエリ結果）をExcelにまとめて出力

### 差別化ポイント

- **ワンストップ**: 操作 + 検証 + エビデンス生成を一気通貫
- **Excel入出力**: 既存の仕様書フォーマットをそのまま使える
- **DB検証**: 画面だけでなくデータの正しさも自動チェック
- **安価/無料**: 商用ツール（年間数十万円）の1/10以下の価格
- **追加インストール最小限**: Python + ブラウザドライバだけで動作

### 技術スタック（案）

- **言語**: Python
- **ブラウザ操作**: Playwright
- **Excel操作**: openpyxl
- **DB接続**: SQLAlchemy（MySQL/PostgreSQL/SQLite対応）
- **GUI**: Tkinter or PyQt（将来的にWeb GUI化も可能）

## 配布・販売戦略

### 課題: 現場持ち込み制約

SI現場では「管理部門が許可していないソフトウェアのインストール禁止」「USB持ち込み禁止」「外部SaaSへのアクセス制限」が一般的。Python + Playwright のツールをそのまま持ち込むのは困難。

### 方式検討

| 方式 | コンプライアンス | 導入ハードル | 結論 |
|---|---|---|---|
| ポータブルexe | △ 未知のexeは審査困難 | × 情シスの壁 | 非現実的 |
| Web SaaS | △ テスト対象が社内LANだと不可 | × 根本的制約 | 単体では不成立 |
| Docker/オンプレ | ◎ 顧客インフラ上 | △ 導入支援が売上 | **有力** |
| Excel VBAマクロ | ◎ 日常的に許可 | ◎ Excel配るだけ | **有力（機能制限あり）** |

### 採用戦略: Lite + Pro ハイブリッド

**VBA Lite版（無料）→ Docker Pro版（有料）のアップセル導線**

1. **VBA Lite版**: Excel VBA + Selenium Basic で基本操作（5種）+ 基本検証（3種）を無料提供
   - 現場でExcelを配るだけで導入可能（コンプライアンス審査不要）
   - 「テスト自動化って便利だ」と実感してもらう営業ツール

2. **Docker Pro版**: 全機能対応（13操作・7検証・DB連携・変数置換・認証自動化）
   - 顧客環境のDockerにデプロイ → 持ち込み制約をクリア
   - 導入支援費（初期50〜100万円）+ 年間保守（20〜50万円/年）

### 収益モデル

```
VBA Lite版（無料） → 現場で効果を実感
       ↓
「DB検証もしたい」「複数シート一括も」「正規表現検証も」
       ↓
Docker Pro版（有料） → 導入支援 + 年間保守契約
```
