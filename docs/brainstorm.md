# 新規事業ブレインストーミング

## 現状の強み（amcompanyの経験から）

- Python（OSC、画像処理、AI推論）
- C#（Unity/Udon）
- AI活用（Stable Audio Open、Real-ESRGAN等のローカルAI）
- BOOTH での個人販売経験
- VRChat エコシステムの知見
- GPU活用（AMD ROCm対応含む）

---

## アイデア候補

### 方向性A: VRChat周辺の横展開

既存の知見を活かしつつ、VRChat以外のソーシャルVRやクリエイター向けに展開。

1. **cluster / Resonite 向けツール移植**
   - VRChatで培ったツールを他プラットフォームに移植
   - 競合が少ない市場で先行者優位を取れる可能性

2. **VTuber向けツール**
   - OBS連携のリアクションオーバーレイ
   - 配信用の音声エフェクト生成（AIベース）
   - サムネイル自動生成の汎用化

### 方向性B: AIツールの一般向け展開

ローカルAI活用のノウハウを別領域に転用。

3. **同人作家向けAIアシスタントツール**
   - イラストのバッチリサイズ・形式変換
   - 入稿データの自動チェック（DPI、カラーモード等）
   - 同人誌表紙テンプレート生成

4. **個人クリエイター向け素材生成ツール**
   - BGM・SE生成（Stable Audio活用）
   - テクスチャ・パターン生成
   - BOOTH/Gumroad等で販売

5. **写真・画像の高画質化サービス**
   - Real-ESRGAN技術をWebアプリ化
   - 古い写真のリストア
   - SNSアイコン高画質化

### 方向性C: 開発者向けツール・SaaS

技術力を活かしたB2B/B2D展開。

6. **Unity開発者向けCI/CDツール**
   - アバター/ワールドのビルド自動化
   - パフォーマンステスト自動実行
   - VRChat SDK対応のCI環境

7. **BOOTHセラー向け管理ツール**
   - 売上分析ダッシュボード
   - 在庫（バージョン）管理
   - 顧客対応テンプレート

### 方向性D: コンテンツ・教育

8. **VRChat開発チュートリアル（有料noteシリーズ）**
   - OSCツール開発入門
   - Unity Editor拡張の作り方
   - 「BOOTHで月1万円稼ぐ」実践ガイド

9. **AIツール活用の技術ブログ → 書籍化**
   - ローカルAI環境構築ガイド
   - AMD GPU(ROCm)でのAI活用（ニッチだが需要あり）

## 評価軸（検討用）

| 軸 | 説明 |
|---|---|
| 既存スキルとの親和性 | 今の技術スタックでどれだけ対応できるか |
| 市場サイズ | ターゲットの人数・支払い意欲 |
| 競合状況 | 既存の競合が少ないか |
| 初期投資 | 時間・コストの最小限で始められるか |
| スケーラビリティ | 成長の余地があるか |
| 継続収益性 | 一回きりでなく持続的に収益を生むか |
