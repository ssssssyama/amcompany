# 新規事業ブレインストーミング

## コアコンセプト

> **情報の非対称性を収益化する** — 「知らない人が知っている人にお金を払う」モデル

### 事業モデル: 課題特化ツール（ツール化型）

技術的知識をGUIソフトウェアに封じ込め、知識がなくても1クリックで成果物を得られるようにする。

- **収益モデル**: ストック型（一度作れば繰り返し売れる）
- **スケーラビリティ**: 高い（限界費用ほぼゼロ）
- **非対称性の源泉**: 「技術的に可能だがやり方がわからない」ギャップ
- **販売チャネル**: BOOTH / Gumroad / 自社サイト

### フォーカス領域: デジタルスキル格差 × ツール選び・活用法

多くの人が「いいツールがあるのに知らない」「知っていても使いこなせない」状態にある。
特に「ローカルAI処理ができること自体を知らない」領域が最大のブルーオーシャン。

## ツールアイデア（競合調査済み）

14案を調査し、強い競合がある8案を除外。以下6案に参入余地あり。

### 特に有望（ブルーオーシャン）

#### 1. AI背景除去ツール（ローカル完結・無料・無制限・GUI）

画像の背景をAIで自動除去するデスクトップアプリ。

- **非対称性**: 「ローカルAIで無料無制限にできる」ことを知らない
- **競合状況**: remove.bg等は全てクラウド+有料制限、rembgはCLIのみ（GUI不在）
- **差別化**: ローカル処理・無料・無制限・日本語GUI の組み合わせが唯一
- **技術**: rembg / U2-Net ベース、Python + GUI（Tkinter or PyQt）
- **既存スキル適合**: ★★★（AI推論・画像処理の経験が直接活きる）
- **開発難易度**: 低（rembgライブラリが成熟）

#### 2. 音声ノイズ除去ツール（AI・ローカル完結）

録音音声のノイズ（風切り音、エアコン、ホワイトノイズ等）をAIで除去するツール。

- **非対称性**: ローカルAI音声処理の存在自体を知らない
- **競合状況**: iZotope RXは高額（数万円）、無料は全てクラウド+制限付き
- **差別化**: ローカル完結・無料・無制限。iZotope RXとの価格差が武器
- **技術**: DeepFilterNet / Demucs ベース
- **既存スキル適合**: ★★★（Stable Audio Openでの音声AI経験が活きる）
- **開発難易度**: 中（モデル選定・チューニングが必要）

#### 3. Excel/CSVクレンジングツール（日本語GUI）

全角半角統一、空白除去、表記揺れ修正、重複削除等をGUIで直感的に実行。

- **非対称性**: クレンジング作業を手動でやっている人が大多数
- **競合状況**: OpenRefineは英語+UIが複雑、日本語GUIツールが不在
- **差別化**: 日本語完全対応・直感的UI・ノーコード
- **技術**: Python + pandas + GUI
- **既存スキル適合**: ★★（Pythonスキルは活きるがドメイン知識は新規）
- **開発難易度**: 中（クレンジングルールの設計が肝）

### 参入余地あり（条件付き）

#### 4. 写真日付/位置情報整理ツール（モダンGUI）

写真のEXIF情報を直感的に編集・整理できるツール。

- **競合**: ExifToolGUIはUIが古く初心者に不向き
- **差別化**: モダンUIでドラッグ&ドロップ操作
- **市場**: ニッチだが安定した需要

#### 5. メール定型文一括送信ツール

- **注意**: スパム対策の法的リスク（特定電子メール法）への対応が必須
- **競合**: 有料サービスが中心（月額4000円〜）

#### 6. Webスクレイピング定期取得ツール

- **注意**: 不正アクセス禁止法・利用規約違反の法的リスクへの対応が必須
- **競合**: Octoparse等の定期取得は有料プランのみ
