## 2. 興味フェーズ: ランディングページの導線

### 現在のLP構成と改善点

```
現在:
  ヒーロー → 機能紹介 → 3ステップ → 競合比較 → CTA

改善後:
  ヒーロー
    → 「今すぐ無料で試す」ボタン（スクロール不要で行動可能）
  ↓
  社会的証明（利用者数、生成数カウンター）
  ↓
  機能紹介（3つのAI機能）
  ↓
  3ステップ説明
  ↓
  Before/After（実際の生成例）★新規追加
  ↓
  競合比較表
  ↓
  FAQ（拡充）
  ↓
  メールアドレス収集セクション ★新規追加
    「転職成功のコツを無料配信」
  ↓
  最終CTA
```

### 追加すべき要素

1. **Before/After セクション**: 「入力 → AI生成結果」の実例を見せる
2. **数字による信頼性**: 「累計○○件生成」カウンター
3. **メール収集**: 記事配信やアップデート通知のためのメルマガ登録
4. **リスク軽減**: 「無料プランはクレジットカード不要」を強調

## 3. 体験フェーズ: 無料→有料の転換設計

### 無料体験の設計

```
初回アクセス（未登録）:
  → 1回だけ無料生成可能（アカウント不要）
  → 生成結果表示 + 「あと2回無料で使うには登録 →」

メール登録後:
  → 追加で月2回無料生成（計3回/月）
  → 生成のたびに残り回数を表示
  → 残り0回で「スタンダードプランで無制限に →」

有料プラン:
  → 無制限生成
  → 志望動機・添削も利用可能
  → PDF保存・履歴保存
```

### キーとなるUXポイント

- **価値を先に体験させる**: 登録前に1回使えるようにする
- **制限の見せ方**: 「残り2回」を常に表示し、希少性を感じさせる
- **アップグレードのタイミング**: 無料枠を使い切った瞬間が最高の転換ポイント

## 4. 転換フェーズ: 課金導線

### Stripe決済フロー

```
料金プランページ
  → 「スタンダードを始める」ボタン
    → ログインチェック（未ログインならログイン画面へ）
      → Stripe Checkout（月額980円）
        → 決済完了 → ダッシュボードへリダイレクト
```

### アップセル導線

```
無料ユーザーが上限に達した時:
  → 「月980円で無制限に使えます」モーダル表示
  → 比較表: 「1回の転職で年収50万UP → 月980円は投資対効果◎」

スタンダードユーザー:
  → 添削機能を使おうとすると「プレミアムで利用可能」
  → 「月+1,000円で添削・面接対策も」
```

### 年額プラン（将来）

- スタンダード年額: 9,800円（月額換算817円、17%OFF）
- プレミアム年額: 19,800円（月額換算1,650円、17%OFF）
- 年額はLTV向上 + 解約率低下に効果的

## 7. 無料リード獲得ツール

SEO記事から集客した後、メールアドレスを獲得するための無料ツール:

### a. 職務経歴書セルフチェックリスト

```
「あなたの職務経歴書は何点？」
  → 10問のチェックリスト（クライアントサイドで完結）
  → 結果表示: 「あなたのスコアは○○点」
  → 「AIで改善しませんか？」→ ツールへ導線
  → 「詳しい改善ポイントをメールで受け取る」→ メール収集
```

### b. 業界別キーワード辞典

- 「IT業界の職務経歴書で使えるアクションワード50選」
- 「営業職の職務経歴書で使うべき数値表現」
- ブログ記事として公開 → メルマガ登録促進
