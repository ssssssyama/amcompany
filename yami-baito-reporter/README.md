# 闇バイト通報支援ツール

闇バイト（違法な裏バイト）の求人を見つけた際に、危険度を判定し、適切な通報先に案内するツールです。

---

## 機能

- **危険度チェックリスト** — 闇バイトの特徴10項目で求人の危険度を判定
- **通報先ガイド** — 警察・相談窓口の連絡先一覧（電話番号コピー・URL表示対応）
- **報奨金制度の説明** — 匿名通報ダイヤル報奨金制度（最大10万円）の詳細
- **通報記録の保存** — チェック結果をローカルにJSON保存

## 必要環境

- Python 3.10以上
- 追加パッケージ不要（Python標準ライブラリのみで動作）

## 使い方

### 直接起動

```
python main.py
```

### Windows（バッチファイル）

```
yami-baito-reporter.bat
```

### ランチャーから起動

```
python launcher.py
```

「社会貢献ツール」セクションの「闇バイト通報支援」をクリック。

## 通報先一覧

| 窓口 | 連絡先 | 用途 |
|------|--------|------|
| 警察相談専用電話 | #9110 | 非緊急の相談 |
| 警察（緊急通報） | 110 | 緊急時 |
| 匿名通報ダイヤル | 0120-924-839 | 匿名通報（報奨金あり） |
| サイバー犯罪相談窓口 | [警察庁サイト](https://www.npa.go.jp/bureau/cyber/soudan.html) | ネット上の犯罪 |
| インターネット・ホットラインセンター | [公式サイト](https://www.internethotline.jp/) | 違法投稿の通報 |
| 消費者ホットライン | 188 | 消費者トラブル |

---

## 注意事項

- このツールは**合法的な通報活動を支援する**ためのものです
- **虚偽の通報は犯罪です**（軽犯罪法第1条16号）
- 身の危険を感じたら**迷わず110番**してください
- 報奨金の支払いは保証されるものではありません
